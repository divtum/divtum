## Hi, I’m Divyesh

I’m an **Electronics & Computer Engineering student** interested in the whole path from a Boolean expression to a working system: digital logic, RTL, computer architecture, FPGA, embedded software, and the hardware/software boundary between them.

I use this profile as an engineering notebook as much as a portfolio. Expect readable Verilog, testbenches, experiments, design notes, and projects that grow in complexity over time.

## Current work

- Building and documenting **Digital System Design labs** in Verilog HDL: combinational logic, sequential circuits, finite-state machines, and verification basics.
- Strengthening foundations in **data structures and algorithms** alongside hardware work.
- Developing the design habits behind larger architecture projects: specifications first, small testable modules, and clear trade-offs.

## How I build

```text
understand the spec → break it into modules → simulate the edge cases
        → document the decisions → measure, debug, iterate
```

I care about engineering work that can be inspected and reproduced: meaningful names, small commits, testbenches beside RTL, and READMEs that explain both *what* works and *why* it was built that way.
